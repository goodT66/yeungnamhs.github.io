# 2027 수능 가채점 대학별 환산 분석 — 개발용 미완성 통합본

이 디렉터리는 기존 `index.html` 정시 입결 조회 화면의 교사 인증 영역에 2027학년도 수능 가채점 성적 조회와 원본 XLSB에서 추출한 563개 환산 유형의 선택 기능을 추가합니다.

## 구현 및 범위
- 원본 XLSB에 기록된 563개 환산 유형명, 대학 그룹을 `catalog.json`에 포함합니다.
- 기존 Firebase 인증 후 기존의 `fetchCsatPrelimRows()`, `fetchCsatPercentileRows()`, `getStudentInfoRowsFromServer()`를 통해 자료를 조회합니다. 공개 CSV나 인증 우회 경로는 사용하지 않습니다.
- 국어·수학·탐구의 표준점수 합계 및 백분위 참고 합계를 계산합니다.
- `calculator.mjs`는 향후 검증된 대학별 환산 규칙을 연결할 수 있는 식 평가 함수를 제공하며, 검증되지 않은 규칙이나 모집단위별 지원선은 임의로 점수·합격예측을 생성하지 않습니다.
- 기존 `main` 브랜치는 수정하지 않았습니다. 배포/병합 전 실제 교사 로그인과 여러 학생의 Excel 원본 대조 검증이 필요합니다.

## 아직 미완료 (중요)
1. XLSB 최종 환산총점의 59~63행 합산이 맞는지 확인한 것은 **원본에 캐시된 한 학생의 563개 사례**입니다. 563개 유형의 *전 영역 환산 계산 공식*을 독립적으로 실행하거나 학생별로 대조 검증한 것은 아닙니다.
2. 대학별 세부 가중치, 등급표, 탐구 변환점수표, 가산점/우수 영역의 완전한 규칙 정의는 아직 빠져 있습니다.
3. 모집단위별 2027학년도 지원선도 검증되지 않았으므로 안정/적정/소신/위험 판정을 보류합니다.
4. 이 코드는 브라우저에서 실제 교사 로그인으로 통합 테스트하지 않았습니다. `node --test admission2027/calculator.test.mjs`는 단위 테스트용입니다.

## 보안
학생의 성적, 원본 XLSB, 수식 추출 전체 및 원본 엑셀의 점수 캐시는 공개 저장소에 포함하지 않습니다. 교사 인증과 원본 데이터 조회 API를 그대로 사용합니다.
